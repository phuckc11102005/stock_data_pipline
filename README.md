# stock_data_pipline
Stock Market Data Pipeline &amp; Alerting System  End-to-end data pipeline tự động thu thập dữ liệu cổ phiếu hàng ngày, lưu trữ theo kiến trúc Medallion (Bronze → Silver → Gold), tính toán 10+ chỉ số kỹ thuật (RSI, MACD, Bollinger Bands...) và gửi cảnh báo thông minh qua Telegram khi phát hiện tín hiệu giao dịch đáng chú ý.
